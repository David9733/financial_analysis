# 📈 기업 재무, 주가 및 거시환경 통합 분석

> 기업의 재무 성과와 주가가 시장지수, 환율, 금리 및 신용 스프레드와 어떻게 움직였는지 일별 데이터로 검증하는 데이터 분석 프로젝트

기업명을 입력하면 재무제표와 시장 데이터를 수집하고 정제하여, 기업별 KPI와 상관분석
결과를 웹에서 비교할 수 있습니다. 일반기업, 금융업 및 보험업을 구분해 서로 다른 재무
구조를 같은 기준으로 억지 비교하지 않는 것을 원칙으로 합니다.

## 🎯 분석 질문

- 기업의 매출, 이익, 수익성 및 재무 안정성은 최근 어떻게 변했는가?
- 기업 주가는 같은 시장(KOSPI/KOSDAQ)과 얼마나 함께 움직였는가?
- 환율, 금리 및 신용 스프레드 변화와 기업 주가 수익률은 어떤 관계가 있었는가?
- 관계는 조회기간 전체에서 일정했는가, 특정 시기에 강해지거나 반대로 바뀌었는가?
- 결측치와 이상치가 분석 결과에 어떤 영향을 줄 수 있는가?

## 🗂️ 분석 데이터

| 영역 | 데이터 | 출처 |
|---|---|---|
| 재무 | 연간 재무제표, 기업 및 업종 정보 | [Open DART](https://opendart.fss.or.kr/) |
| 주가 | 일별 OHLC, 거래량, 거래대금, 시가총액 | [공공데이터포털](https://www.data.go.kr/) 금융위원회 |
| 시장 | KOSPI 또는 KOSDAQ 일별 종가 | [공공데이터포털](https://www.data.go.kr/) 금융위원회 |
| 환율 | 원/달러 매매기준율 | [한국수출입은행](https://www.koreaexim.go.kr/) |
| 금리 | 국고채 3년, 회사채 3년 AA- | [한국은행 ECOS](https://ecos.bok.or.kr/api/) |
| 신용 위험 | 회사채 3년 AA- − 국고채 3년 | [한국은행 ECOS ](https://ecos.bok.or.kr/api/) 금리로 직접 계산 |

기업의 `시장구분`이 KOSPI이면 KOSPI, KOSDAQ이면 KOSDAQ 지수를 연결합니다.
여러 시장의 기업을 함께 분석해도 기업별 기준지수가 섞이지 않습니다.

## 🔬 분석 설계

### 1. 재무 분석

- 연결재무제표를 우선 사용하고 없으면 별도재무제표를 조회합니다.
- 표준 계정 ID와 기업별 계정명을 함께 사용해 필요한 계정을 매칭합니다.
- 계정 구성을 기준으로 일반기업, 금융업 및 보험업을 판별합니다.
- 비교연도나 원천 계정이 없으면 값을 추정하지 않고 사유를 표시합니다.

| 대상 | 주요 지표 |
|---|---|
| 공통 | 영업이익, 당기순이익, ROE, ROA, 자산 및 이익 성장률 |
| 일반기업 | 매출 성장률, 영업이익률, 순이익률, 부채비율, 이자보상배율, 매출채권 회전일수 |
| 금융업 | 순이자손익, 순수수료손익 |
| 보험업 | 보험서비스수익과 손익, 투자손익, 보험서비스마진 |

### 2. 일별 시계열 변환

수준값의 공통 추세로 인한 허위상관을 줄이기 위해 주 분석에는 하루 변화량을 사용합니다.

| 변수 | 분석값 | 계산 |
|---|---|---|
| 기업 주가 | 일간 수익률(%) | `(오늘 종가 ÷ 전일 종가 - 1) × 100` |
| 시장지수 | 일간 수익률(%) | `(오늘 지수 ÷ 전일 지수 - 1) × 100` |
| 원/달러 환율 | 일간 변화율(%) | `(오늘 환율 ÷ 전일 환율 - 1) × 100` |
| 국고채 3년 | 변화폭(bp) | `(오늘 금리 - 전일 금리) × 100` |
| 신용 스프레드 | 변화폭(bp) | `오늘 스프레드 - 전일 스프레드` |

주식 거래일을 기준으로 다른 시계열을 결합합니다. 빈 값은 제한적으로 직전 값으로
채우되, 보간 구간은 상관계수와 이상치 계산에서 제외합니다. 하루 변화의 IQR 범위를
벗어난 날은 삭제하지 않고 원인 확인 대상으로 표시합니다.

### 3. 상관분석과 시각화

| 결과 | 확인할 질문 |
|---|---|
| 산점도와 점선 추세선 | 환율 변화율과 금리 변화폭은 어떤 방향으로 움직였는가? |
| 상관관계 히트맵 | 주가, 시장, 환율, 금리 및 신용 스프레드 관계의 방향과 강도는 무엇인가? |
| 이동상관 | 관계가 강해지거나 약해지고, 부호가 바뀐 구간이 있는가? |
| 하루 변화와 이상치 차트 | 결과에 영향을 줄 수 있는 급격한 변화가 언제 있었는가? |

히트맵은 자기 자신과의 상관계수 `1.00`을 가려 변수 간 관계에 집중합니다. 이동상관은
주가 수익률과 시장지수, 환율, 금리 및 신용 스프레드의 네 관계만 보여 줍니다.

| 조회기간 | 이동상관 창 |
|---|---:|
| 1개월 | 10거래일 |
| 3개월 | 20거래일 |
| 6개월, 1년 및 3년 | 60거래일 |

창이 채워지기 전 값이 비어 있어 이동상관 차트가 늦게 시작하는 것은 정상입니다.

## 💡 히트맵 종합 인사이트

상관계수의 절댓값으로 관계의 강도를 구분합니다.

| 절댓값 | 표시 | 종합 판단 사용 |
|---:|---|---|
| \|r\| < 0.3 | 약함 | 제외 |
| 0.3 ≤ \|r\| < 0.7 | 중간 | 포함 |
| \|r\| ≥ 0.7 | 강함 | 포함하고 강한 신호로 표시 |

중간 이상 상관계수의 부호와 조회기간의 실제 요인 방향을 결합해 `주가 상승 방향`과
`주가 하락 방향` 신호를 요약합니다. 유효 신호가 2개 미만이면 판단을 유보합니다.

> 이 인사이트는 선택기간의 과거 동행성을 설명합니다. 기업 실적의 원인, 재무적으로
> 버틸 수 있는 능력 또는 미래 주가를 의미하지 않습니다.

## 🚀 빠른 시작

### 1. 저장소와 API 키 준비

```powershell
git clone https://github.com/David9733/financial_analysis.git
cd financial_analysis
Copy-Item .env.example .env
```

`.env`에 사용할 API 키를 입력합니다. 재무분석에는 `DART_KEY`가 필요하고 나머지
키는 해당 데이터와 GPT 기능을 사용할 때 필요합니다.

```text
DART_KEY=발급받은_Open_DART_API_키
PUBLIC_STOCK_API_KEY=공공데이터포털_서비스키
KOREAEXIM_API_KEY=수출입은행_인증키
ECOS_API_KEY=ECOS_인증키
OPENAI_API_KEY=OpenAI_API_키
OPENAI_MODEL=gpt-4o-mini
```

### 2. 웹 실행

```powershell
uv run --python 3.10 --isolated --with-requirements requirements.lock src/app.py
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다.

### 3. 테스트

```powershell
uv run --python 3.10 --isolated --with-requirements requirements.lock --with pytest -m pytest -q
```

외부 API는 테스트에서 가짜 응답으로 대체하므로 네트워크와 API 키 없이 실행됩니다.

## ⚠️ 해석 시 주의사항

- 상관관계는 인과관계가 아닙니다.
- 환율값–금리값 수준상관은 공통 추세 때문에 높아질 수 있어 변화량 상관과 함께 봅니다.
- 1개월 결과는 관측 수가 적어 일부 날짜에 민감하므로 장기 결과와 함께 확인합니다.
- 신용 스프레드는 시장 전반의 기업 신용위험 지표이며 개별 기업의 실제 차입금리가 아닙니다.
- KOSPI/KOSDAQ은 반영하지만 업종지수는 사용하지 않아 업종 효과를 분리하지 못합니다.
- 이상치는 오류로 단정하지 않고 공시나 뉴스로 원인을 추가 확인해야 합니다.
- 결과는 공개 데이터 탐색용이며 투자, 매수 혹은 인수 권고가 아닙니다.
