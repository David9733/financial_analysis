# DART 기업 재무분석

기업명을 입력하면 Open DART의 연간 전체 재무제표를 가져와 Pandas로 재무지표를 계산하고 CSV와 PNG 차트를 생성합니다. 계정 구성을 기준으로 일반기업·금융업·보험업을 자동 구분합니다.

## 설치와 실행

프로젝트 루트 `.env`에 아래 둘 중 하나를 설정합니다. 기존 `DART_KEY`도 그대로 사용할 수 있습니다.

```text
DART_KEY=발급받은_API_키
```

PowerShell에서 실행합니다.

```powershell
cd DART/dart_financial_analysis
python -m pip install -r requirements.txt
python main.py
```

## 웹 화면 실행

uv가 설치된 환경에서는 별도의 `.venv`나 전역 `pip install` 없이 아래 명령으로
의존성을 임시 격리 환경에 준비할 수 있습니다. 실행 후 브라우저에서
`http://127.0.0.1:5000`을 엽니다.

```powershell
uv run --isolated --with-requirements requirements.txt app.py
```

uv 관리 Python은 PEP 668 정책에 따라 `python -m pip install`로 시스템 환경을
직접 변경하는 것을 차단합니다. `--break-system-packages`로 우회하지 않는 것을
권장합니다.

기업명 입력칸은 추가·삭제 버튼으로 최대 10개까지 만들 수 있습니다.
한 기업은 연도별 추세 차트, 두 기업 이상은 최근 공통 연도의 비교 차트를
표와 함께 보여줍니다. `SK하이닉스`, `에스케이하이닉스`, `SK 하이닉스`처럼
영문 브랜드의 한글 발음과 공백 차이도 같은 기업명으로 검색합니다.
`현대그린`, `에스케이하닉스`, `삼성전짜`처럼 일부 이름만 입력하거나
약간의 오타가 있어도 유사한 상장사를 찾으며, 후보가 모호하면 비슷한 기업
목록을 안내합니다.

`main.py` 위쪽의 `COMPANIES`를 수정하면 됩니다.

```python
COMPANIES = ["삼성전자"]
# 또는
COMPANIES = ["삼성전자", "SK하이닉스", "LG전자"]
```

다른 코드에서 호출할 수도 있습니다.

```python
from main import run_analysis

result = run_analysis(["삼성전자"], show_charts=True)
```

## 계산 기준

- 분석 기준: 연결재무제표(CFS), 없으면 별도재무제표(OFS)
- 공통 지표: 영업이익, 당기순이익, 총자산, 부채총계, 자본총계, ROE, 총자산·영업이익·당기순이익 성장률
- 일반기업: 매출, 영업이익률, 부채비율, 이자보상배율, 매출성장, 매출채권회전일수
- 금융업: 순이자손익, 순수수료손익. 매출·영업이익률·이자보상배율·매출채권회전일수는 적용하지 않음
- 보험업: 보험서비스수익, 보험서비스손익, 보험서비스마진, 보험서비스수익 성장률, 투자손익
- ROE: 당기순이익 / 평균자본 × 100
- 보험서비스마진: 보험서비스손익 / 보험서비스수익 × 100
- 매출채권회전일수: 기말 매출채권 / 매출 × 365

내부 계산에서는 원천 데이터가 없거나 분모가 0인 결과를 결측치로 유지합니다. CSV에서는 빈칸 대신 `해당 없음(업종)`, `비교연도 없음`, `원천 데이터 없음`처럼 이유를 표시합니다.

## 출력

- `output/financial_analysis.csv`: 최종 분석 결과
- `output/charts/`: 단일 기업 추세 또는 최근 공통 연도 기업 비교 차트

기업 고유번호 목록과 원천 재무 데이터는 실행 중에만 메모리에서 사용되며 별도로 저장되지 않습니다.
